# What Emissions Hide: Replication Materials

Data and code repository for **What Emissions Hide: Energy Use, Carbon Intensity, and Stock Return Predictability**.

**Authors:** Yunlong Chen, Difang Huang, Zhuozhen Peng, Yuxin Ran, and Shouyang Wang.

**Manuscript version:** November 8, 2026.  
**Repository established:** November 9, 2026.

## Release status

Replication materials are being organized and will be added progressively to this repository. This initial release provides the permanent repository link and describes the planned data and code contents. Executable replication code and data files will accompany subsequent releases.

## Contents

- [Data](data/README.md): sources, analysis inputs, and documentation.
- [Code](code/README.md): data construction, forecasting, inference, and table and figure generation.

The empirical analysis studies whether decomposing fossil carbon dioxide emissions into energy use and effective carbon intensity improves forecasts of cumulative U.S. market excess returns. The main analysis uses monthly observations from January 1990 through December 2025, with recursive forecast evaluation beginning in January 2010.

Updates will retain this repository address so that the link in the manuscript continues to point to the replication materials.
